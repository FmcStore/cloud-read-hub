# Cloud Read Hub

- Sistem Login & Register (MongoDB): User bisa mendaftar dengan Email & Password.

- Cloud Sync: Riwayat baca (History) dan Bookmark otomatis tersimpan di database. Jika ganti HP/Device dan login, data akan kembali. 

- PWA Support: Website bisa diinstall sebagai aplikasi

- Upgrade Ui/UX
